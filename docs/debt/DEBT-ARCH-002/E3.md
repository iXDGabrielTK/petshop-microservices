## Invariantes
- **Q1** — **Integração Checkout → Inventory: chamada síncrona in-process via Open Host Service em `inv.inventory.api`, com `Propagation.MANDATORY` na implementação.** O ACID vale **por operação**: a reserva (`iniciarVenda`) e a baixa (`VendaEventHandler`, via webhook → evento → RabbitMQ) são transações distintas. A consistência entre elas é garantida pelo modelo **reserva → baixa / estorno**, não por uma transação única.
  - **Impacto:** Sem consistência eventual na reserva do PDV. A resposta do `POST` de venda continua sendo "estoque reservado ou erro" na mesma transação. Nenhum evento novo é necessário. O teste `EstoqueCommandServiceIT.semTransacaoAtivaFalha` prova o `MANDATORY` (`IllegalTransactionStateException`).
- **Q4** — **JPA:** `ItemVenda.produto` (`@ManyToOne Produto`) vira `@Column(name = "produto_id", nullable = false, updatable = false) Long produtoId`. `Venda.adicionarItem` passa a receber tipos escalares (`Long produtoId, String nomeProduto, BigDecimal precoUnitario, BigDecimal quantidade`), instanciando `ItemVenda` via factory (`ItemVenda.criar(...)`) que garante invariantes. **PostgreSQL:** `fk_itens_venda_produto` e `fk_movimentacoes_venda` **permanecem**, documentadas como *FKs de fronteira modular*, a remover só se os schemas forem separados fisicamente.
  - **Impacto:** **Nenhuma migration estrutural.** A coluna `produto_id` e a FK já existem ([V1#L23-L32](../../../apps/inv-service/src/main/resources/db/migration/V1__Schema_Inicial.sql#L23-L32)). A documentação no schema é uma migration **só de metadados** (`COMMENT ON CONSTRAINT`) na E5. `MovimentacaoEstoque` já usa `Long vendaId`, então não surge ciclo em Java.
- **Q9** — **Refatoração com paridade funcional.** Erro de indisponibilidade continua reportando **só o primeiro produto faltante**, com a **mensagem exata** atual (`"Estoque insuficiente para o produto: " + nome`). Sem consolidar itens duplicados e sem validar produto inativo. **Única exceção:** o guard de `CANCELADA` (Q10), em commit isolado red-green.
  - **Impacto:** **Nuance documentada:** com a ordenação da Q3, "primeiro faltante" passa a significar o primeiro **em ordem de `produtoId`**, não na ordem do request. Só faz diferença com **2+ produtos faltantes no mesmo carrinho**; o formato da mensagem é idêntico. **Correção colateral inevitável (F6):** o alerta anti-spam passa a usar a pré-imagem exata calculada sob o row lock, então deixa de disparar alertas duplicados sob concorrência (comportamento estritamente melhor; ver a seção 2.3 de [E2.md](./E2.md)).
- **F3** (🔴 Bloqueante) — **Acoplamento de entidade JPA entre contextos.** `ItemVenda` declara `@ManyToOne(fetch = LAZY) @JoinColumn(name = "produto_id") Produto produto`. `Venda.adicionarItem(Produto, BigDecimal)` lê `produto.getNome()`/`getPrecoVenda()`. São as 3 violações congeladas em R8.
  - **Evidência:** [ItemVenda.java#L25-L27](../../../apps/inv-service/src/main/java/inv/checkout/domain/model/ItemVenda.java#L25-L27), [Venda.java#L51-L65](../../../apps/inv-service/src/main/java/inv/checkout/domain/model/Venda.java#L51-L65), [f3ae93b8-…-070c0c3c81d9#L1-L3](../../../apps/inv-service/src/test/resources/archunit_store/f3ae93b8-4392-4cb4-9c5a-070c0c3c81d9#L1-L3)
  - **Impacto:** `Long produtoId` (ID por referência) + parâmetros escalares em `Venda.adicionarItem(Long, String, BigDecimal, BigDecimal)` e factory `ItemVenda.criar(...)` (Q4). Mesma coluna física, sem migration (**E3**).
- **F4** (🟠 Alta) — **Checkout injeta o caso de uso interno `EstoqueService`** (público, recebe a entidade `Produto`) em `VendaService` e em `VendaEventHandler`.
  - **Evidência:** [VendaService.java#L35-L45](../../../apps/inv-service/src/main/java/inv/checkout/usecase/VendaService.java#L35-L45), [VendaEventHandler.java#L14](../../../apps/inv-service/src/main/java/inv/checkout/infrastructure/messaging/VendaEventHandler.java#L14) e [#L63-L65](../../../apps/inv-service/src/main/java/inv/checkout/infrastructure/messaging/VendaEventHandler.java#L63-L65)
  - **Impacto:** Porta pública `inv.inventory.api.EstoqueCommandService` (**E2**); `EstoqueService` vira package-private e passa a implementá-la (**E3**).

### 2.4 Checkout — domínio (`ItemVenda` e `Venda`)

Conforme `Q4` e `F3`, [`ItemVenda`](../../../apps/inv-service/src/main/java/inv/checkout/domain/model/ItemVenda.java) substitui `@ManyToOne Produto` por `@Column(name = "produto_id", nullable = false, updatable = false) Long produtoId` e expõe a factory package-private `ItemVenda.criar(...)` com validação de invariantes:

```java
package inv.checkout.domain.model;

import jakarta.persistence.*;
import lombok.AccessLevel;
import lombok.Getter;
import lombok.NoArgsConstructor;

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.Objects;

@Entity
@Table(name = "itens_venda")
@Getter
@NoArgsConstructor(access = AccessLevel.PROTECTED)   // exigido pelo JPA
public class ItemVenda {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "venda_id", nullable = false)
    private Venda venda;

    /**
     * ID por referência ao agregado Produto (Bounded Context Inventory).
     * A FK física fk_itens_venda_produto é mantida como "FK de fronteira modular" (ADR-0001, adendo DEBT-ARCH-002).
     */
    @Column(name = "produto_id", nullable = false, updatable = false)
    private Long produtoId;

    @Column(nullable = false)
    private String nomeProdutoSnapshot;

    @Column(nullable = false, precision = 10, scale = 2)
    private BigDecimal precoUnitarioSnapshot;

    @Column(nullable = false, precision = 10, scale = 3)
    private BigDecimal quantidade;

    static ItemVenda criar(
            Venda venda,
            Long produtoId,
            String nomeProdutoSnapshot,
            BigDecimal precoUnitarioSnapshot,
            BigDecimal quantidade) {
        Objects.requireNonNull(venda, "venda é obrigatória");
        if (produtoId == null || produtoId <= 0) {
            throw new IllegalArgumentException("produtoId deve ser positivo");
        }
        if (nomeProdutoSnapshot == null || nomeProdutoSnapshot.isBlank()) {
            throw new IllegalArgumentException("nomeProdutoSnapshot é obrigatório");
        }
        if (precoUnitarioSnapshot == null || precoUnitarioSnapshot.compareTo(BigDecimal.ZERO) < 0) {
            throw new IllegalArgumentException("precoUnitarioSnapshot não pode ser negativo");
        }
        if (quantidade == null || quantidade.compareTo(BigDecimal.ZERO) <= 0) {
            throw new IllegalArgumentException("quantidade deve ser positiva");
        }
        ItemVenda item = new ItemVenda();
        item.venda = venda;
        item.produtoId = produtoId;
        item.nomeProdutoSnapshot = nomeProdutoSnapshot;
        item.precoUnitarioSnapshot = precoUnitarioSnapshot;
        item.quantidade = quantidade;
        return item;
    }

    public BigDecimal getSubTotal() {
        if (quantidade == null || precoUnitarioSnapshot == null) {
            return BigDecimal.ZERO.setScale(2, RoundingMode.HALF_EVEN);
        }
        return quantidade.multiply(precoUnitarioSnapshot).setScale(2, RoundingMode.HALF_EVEN);
    }
}
```

### 2.5 Checkout — casos de uso (`VendaService` e `VendaEventHandler`)

[`VendaService`](../../../apps/inv-service/src/main/java/inv/checkout/usecase/VendaService.java) no estado final (pós-E4). `buscarStatusVenda` e `recuperarVendaAtiva` ficam inalterados:

```java
@Slf4j
@Service
public class VendaService {

    private final VendaRepository vendaRepository;
    private final CatalogoQueryService catalogoQueryService;
    private final EstoqueCommandService estoqueCommandService;

    public VendaService(VendaRepository vendaRepository,
                        CatalogoQueryService catalogoQueryService,
                        EstoqueCommandService estoqueCommandService) {
        this.vendaRepository = vendaRepository;
        this.catalogoQueryService = catalogoQueryService;
        this.estoqueCommandService = estoqueCommandService;
    }

    @Retryable(
            retryFor = { OptimisticLockingFailureException.class, PessimisticLockingFailureException.class },   // Q8
            backoff = @Backoff(delay = 150, maxDelay = 500, random = true)
    )
    @Transactional
    public Venda iniciarVenda(VendaRequest pedido) {
        log.debug("Processando início de venda. Verificando disponibilidade de estoque...");

        Map<Long, ProdutoCheckoutView> produtos = carregarCatalogo(pedido);
        Venda venda = vendaRepository.save(new Venda());           // IDENTITY: id disponível para o comando

        for (ItemVendaRequest itemRequest : pedido.itens()) {
            ProdutoCheckoutView prod = produtos.get(itemRequest.produtoId());
            venda.adicionarItem(prod.id(), prod.nome(), prod.precoVenda(), itemRequest.quantidade());
        }

        estoqueCommandService.reservar(comandoPara(venda));        // lote; ordem de lock é responsabilidade do Inventory
        venda.irParaPagamento();
        return vendaRepository.save(venda);
    }

    // buscarStatusVenda(...) e recuperarVendaAtiva() — inalterados

    @Transactional
    public void cancelarVendaExpirada(Long vendaId) {
        Venda venda = vendaRepository.findByIdWithLock(vendaId)
                .orElseThrow(() -> new BusinessException("Venda não encontrada"));

        switch (venda.getStatus()) {                                // guard pós-lock (F2 / Q10)
            case CANCELADA -> {
                log.info("Venda {} já está CANCELADA; expiração ignorada (idempotente).", vendaId);
                return;
            }
            case ABERTA, AGUARDANDO_PAGAMENTO -> { /* elegível: segue */ }
            default -> throw new BusinessException(
                    "Venda #" + vendaId + " não é elegível para cancelamento por expiração no status: " + venda.getStatus());
        }

        venda.cancelar();
        estoqueCommandService.estornarReserva(comandoPara(venda));
        vendaRepository.save(venda);
    }

    private static ComandoEstoqueVenda comandoPara(Venda venda) {
        return new ComandoEstoqueVenda(
                venda.getId(),
                venda.getItens().stream()
                        .map(item -> new ItemComando(item.getProdutoId(), item.getQuantidade()))
                        .toList());
    }

    private Map<Long, ProdutoCheckoutView> carregarCatalogo(VendaRequest pedido) {
        Set<Long> ids = pedido.itens().stream().map(ItemVendaRequest::produtoId).collect(Collectors.toSet());
        Map<Long, ProdutoCheckoutView> map = catalogoQueryService.buscarParaCheckout(ids).stream()
                .collect(Collectors.toMap(ProdutoCheckoutView::id, Function.identity()));
        if (map.size() != ids.size()) {
            throw new ResourceNotFoundException("Um ou mais produtos não foram encontrados.");   // mensagem idêntica
        }
        return map;
    }

    @SuppressWarnings("unused")
    @Recover
    public Venda recuperarFalhaDeConcorrencia(ConcurrencyFailureException e, VendaRequest pedido) {   // cobre otimista + pessimista
        log.warn("⚠️ Limite de retries atingido por contenção de lock no estoque. Venda abortada.");
        throw new BusinessException(
                "Alta concorrência nos itens selecionados. O estoque foi atualizado por outro caixa. Por favor, tente finalizar novamente.");
    }

    @SuppressWarnings("unused")
    @Recover
    public Venda recuperarFalhaGeral(RuntimeException e, VendaRequest pedido) {
        throw e;
    }
}
```
